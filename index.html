05 / FAQ

你可能想知道。

关于应用与站点支持的简短说明。

EasyDownloader 是什么？＋

EasyDownloader 是一个 Windows 桌面媒体素材下载工具。它通过解析器处理你提交的公开链接，并把获取的文件保存到本地。

列表里的站点都保证可下载吗？＋

不保证。清单用于展示测试覆盖范围与候选站点。站点结构、地区、登录状态、版权策略及链接有效期都会影响结果。

需要登录或 cookies.txt 吗？＋

公开内容通常可先直接测试。若内容本身需要授权登录，客户端可使用用户主动选择的浏览器导出 Cookie 文件；请只用于自己有权访问的内容，并妥善保管。

可以下载付费或受保护内容吗？＋

请勿使用本软件绕过 DRM、付费墙、访问控制或平台限制。仅保存你拥有或获准保存的内容，并遵守当地法律与网站条款。

如何反馈问题或建议？＋

可在本页留言，或前往 GitHub 提交反馈。请勿在公开留言中粘贴 Cookie、私人链接或个人敏感信息。
